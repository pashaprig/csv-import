# CSV Project

Цей проєкт — простий фронтенд для підготовки CSV-файлів з текстових розвідувальних повідомлень.

## Опис

Користувач може вставити текст у поле, де кожен рядок опису складається з координат та інших даних, розділених дефісами. Натиснувши кнопку, програма формує таблицю з вибраними CSV-колонками, дозволяє редагувати значення, вибирати геометрію і зберігати результат у CSV-файл.

## Функції

- Парсинг тексту з textarea
- Відображення таблиці з редагованими полями
- Перемикання видимих колонок через чекбокси
- Вибір типу геометрії (`Point`, `LineString`, `Polygon`)
- Експорт даних у CSV-файл

## Структура

- `index.html` — головна сторінка інтерфейсу
- `styles.css` — стилі сторінки
- `scripts/consts.js` — конфігурація колонок та геометрії
- `scripts/scripts.js` — логіка підготовки таблиці та експорту CSV

## Як використовувати

1. Відкрийте `index.html` у браузері.
2. Вставте текст у поле введення.
3. Оберіть потрібні колонки.
4. Натисніть `Підготувати таблицю`.
5. Натисніть `Зібрати текст`, щоб завантажити CSV.

## Примітки

- CSV генерується з повним цитуванням полів.
- Якщо поле `coordinates` не містить готову геометрію, воно автоматично обгортається у вибраний тип геометрії.
